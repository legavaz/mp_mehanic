# AGENTS.md — правила проекта «ИСТК Механики»

## Правило 1. Проверка модулей через BSL Check

После каждого изменения любого модуля 1С (`.bsl`) — отправлять изменённые файлы на проверку
инструментом `bsl-check_check_files` и обрабатывать результат:

- реальные замечания (ошибки, потенциальные дефекты) — исправлять;
- ложные срабатывания (например `UnusedLocalVariable` для реквизитов формы без контекста формы)
  — устранять переработкой кода (квалификация `ЭтаФорма.`) или явно пояснять как ложные;
- результат проверки отражать в отчёте по задаче.

## Правило 2. Префикс кастомности имён

Новые имена — объекты метаданных, реквизиты, измерения, ресурсы, методы, команды форм —
имеют префикс **`мх`**.
